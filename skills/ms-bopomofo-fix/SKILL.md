# 微軟注音學習詞修正

## 先知道的事實

- 學到的詞存在 `%APPDATA%\Microsoft\IME\15.0\IMETC\TCHFTL.DAT`（二進位，格式見 `reference/format.md`）。每筆有：文字、每個字的注音碼、被選次數。
- **亂選的主因**：打錯的詞（事什麼）和正確的同音詞（是什麼）都被學進去，被選次數差不多，輸入法就忽左忽右。
- **輸入法引擎跑在 `ctfmon.exe` 裡**。它開機後讀一次檔案，之後用記憶體裡的資料，不定時整份寫回。
  - 只改檔案不重啟：沒效果，而且會被舊資料蓋回去。
  - 必須**強制結束** ctfmon（讓它正常關閉會先存檔），換檔，再啟動。
  - ctfmon 是高權限程式，一定要系統管理員權限，會跳 UAC。
- **內建的官方檢視工具**：`%SystemRoot%\System32\IME\shared\IMCCPHR.exe /TC /PHRUI`（微軟注音使用者造詞工具）的「常用新詞」分頁，可以看、刪除、匯出。但**只顯示前 2500 筆**，後面的看不到也刪不到。
- **替換只能換成同注音的字**。檔案裡的注音碼不動，只改顯示的字。注音本身就打錯的詞（按錯鍵組出沒有意義的詞）沒有正確寫法，只能刪除。
- 只在 Windows 11 24H2（build 26100）、從 WSL 執行時驗證過（Windows 原生 `py -3` 跑 `apply` 還沒實測）。工具寫入前會檢查檔頭；`info` 回報 `format_ok: false` 就停手，不要硬改。

## 工具

`scripts/bopomofo_tool.py`：只用標準函式庫，一個檔案。
- Windows 執行：`py -3 <路徑>\bopomofo_tool.py <指令>`
- WSL 執行：`python3 <路徑>/bopomofo_tool.py <指令>`

路徑會自動抓（WSL 會透過 `cmd.exe` 取 `%APPDATA%`）。每個指令都可以加 `--json`。

| 指令 | 用途 |
|---|---|
| `info` | 環境、資料夾、格式檢查、筆數、學習設定、ctfmon PID |
| `dump [--grep 字] [--sort count] [--limit N]` | 列出學到的詞：編號、次數、詞、注音、官方工具看不看得到 |
| `suspects` | 同一串注音學到不同寫法的詞（錯字，或 甚麼/什麼 這種異體混用） |
| `udp` | 使用者自建詞 |
| `plan --fix 錯=正 --delete 詞 --delete-index N --dedupe` | 試跑，不寫入 |
| `apply`（參數同 plan） | 自動備份 → 一次 UAC（停 ctfmon → 確認檔案沒被動過 → 換檔 → 啟動 ctfmon）→ 驗證 |
| `backup` / `restore <備份資料夾>` / `restart-ctfmon` | 備份、還原（也走 UAC）、只重啟 ctfmon。`restore` 和 `restart-ctfmon` 還沒實測過 |

- `--fix` 是子字串替換，會套用到所有含那個錯字詞的紀錄。單字替換（例如 `在=再`）會改到太多詞，預設拒絕，要加 `--allow-single` 才會執行。如果改完跟既有的同注音詞重複，會自動併成一筆（次數相加）。
- `--dedupe` 把同字同注音的重複紀錄併成一筆。
- 備份預設放在 `%USERPROFILE%\IME_backup\<時間戳>\`，可用 `--backup-root` 改。

## 流程

1. **`info`**：確認 `format_ok: true`。順便記下 `hidden_in_ui`（官方工具看不到的筆數）。
2. **找學壞的詞**
   - 先問使用者最常被選錯的例子，用 `dump --grep` 查。
   - 跑 `suspects` 看同音衝突。
   - 跑 `dump --sort count --json`，**全部讀過一遍**，挑出疑似錯字：
     - 同音錯字：事什麼、寶底、選像、來的急…
     - 注音按錯鍵學到、讀不通的詞。
     - 同一個詞在清單裡有兩種寫法。
   - 這些是正常的，不要動：「的設」「看一」這類片段是輸入中途被學起來的，不算錯；人名、遊戲名、公司內部術語看起來怪，但可能是對的。
3. **跟使用者確認**：列一張表，每一筆寫上建議做法：
   - **替換**：有同音的正確寫法。
   - **刪除**：注音本身就錯，沒有正確寫法。
   - **保留**。
   不確定的（專有名詞、甚麼/什麼 這種寫法偏好）一定要問，不要自己決定。
4. **`plan`**：**整份清單都要看過**，因為 `--fix` 會改到所有含那個錯字詞的紀錄。錯字詞寫得越長越精準；單字替換預設會被拒絕。給使用者看結果。每個被換的字都會標注音，例如 `事→是[ㄕˋ]`。出現「(無佐證，請人工確認讀音)」的，表示新字在學習紀錄裡沒有以這個注音出現過，要確認新字真的唸這個音。
5. **`apply`**：執行前先告訴使用者「等一下會跳出 UAC，請按是」。看結果：
   - `result` 是 `OK ...`，而且 `verify.written`、`verify.ctfmon_restarted` 都是 true、`remaining` 是 0：成功。
   - `CHANGED`：準備期間輸入法剛好寫了檔，工具已放棄寫入，重跑 `apply` 就好。
   - `ERROR 沒有取得系統管理員權限`：使用者按了取消，或沒看到 UAC 視窗。
6. **請使用者實測**：開一個新的記事本，打那組注音，看第一候選是不是對的。
7. 出問題就用 `restore <備份資料夾>` 還原。

## 使用者想自己在介面上操作時

1. 開 `IMCCPHR.exe /TC /PHRUI` → 「常用新詞」分頁 → 選取 → 刪除 → **存檔或關閉視窗**（沒存檔就不會寫入）。
2. 存完一定要跑 `restart-ctfmon`，不然 ctfmon 記憶體裡的舊資料可能會把刪除蓋回去。
3. 第 2501 筆之後的詞只能用 `apply --delete`。

## 不要做的事

- 不要在 ctfmon 還在跑的時候直接覆寫學習檔。一律用 `apply` 或 `restore`。
- 不要用滑鼠或鍵盤自動化去點使用者桌面上的視窗（座標會受 DPI 和視窗位置影響，也可能點到使用者正在用的視窗）。介面操作請使用者自己來。
- 不要改注音碼，也不要把詞換成不同注音的字。
- 不要動 `TCHFTS.DAT`、`TCLRN.IMD`（格式未完全解開）。
- 沒有使用者確認，不要刪除或合併任何詞。

## 預防

學習開關在 registry `HKCU\Software\Microsoft\IME\15.0\IMETC`：
- `Enable New Phrase Learning`：新詞學習
- `Enable Personal Regulating`：依個人習慣調整

關掉就不會再學到錯字，但也不會再學新術語。要不要關由使用者決定。打錯時先修正再送出，是最根本的預防。
